# Bulmaca Atölyesi 🧩

Ortaokul öğrencileri için **çengel ve klasik bulmaca üreten** web uygulaması.

Bu web sitesi, **ALKEV Özel Okulları Bilişim ve Türkçe bölümlerinin** işbirliğiyle hazırlanmıştır.

## Özellikler

- ✏️ Kendi kelimelerinizle bulmaca oluşturma (`kelime: ipucu` biçimi desteklenir)
- 📚 Kelimeler yetmezse tema ve sınıf seviyesine uygun hazır havuzdan otomatik tamamlama (6 tema, ~130 kelime)
- 🔀 İki stil: **Klasik** (numaralı kareler + ipucu listeleri) ve **Çengel** (ipuçları ızgara içinde, oklu)
- 🎮 Ekranda çözme: kontrol, çözümü gösterme, konfetili kutlama
- 🖨️ Yazıcı dostu tek sayfa A4 çıktı — boş ya da cevap anahtarlı, PDF olarak kaydedilebilir
- 🌗 Aydınlık / karanlık tema desteği

## Kullanım

`index.html` dosyasını tarayıcıda açmanız yeterli — kurulum, sunucu ya da internet bağlantısı gerekmez.

İsteğe bağlı adres parametresi: `index.html?stil=klasik` ya da `?stil=cengel` ile açılış stili seçilebilir.
